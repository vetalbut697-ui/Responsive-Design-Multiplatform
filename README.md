# Responsive-Design-Multiplatform
Для розміщення треба робити позицію через відсотки а потім вже робити відступ від країв у пікселях; 
Для того що інтерфейс не обрізався гранями безпечних зон телефонів - потрібно прибрати галочку на ClipToDeviceSafeArea; 
Для роботи з консолями/джойстиками потрібно використовувати ContextActionService та GuiService, на тих елементах що можна буде вибирати повинна стояти галочка Selectable, при роботі з ContextActionService потрібно робити функції що будуть активуватись по кнопці. 
Треба ще додати те що по суті процес роботи при натисканні кнопок у клавіатури і джойстика присвоєння дій до кнопок має один і той самий принцип.
